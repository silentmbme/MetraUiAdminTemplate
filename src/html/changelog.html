Version 1.0.0

Current release overview

v1.0.0Current package version

The initial package brings together the template foundations, dashboard pages, application examples, and third-party integrations.

Included in this package

  • Responsive template foundations

    Bootstrap 5 layouts, shared HTML template parts, theme colors, typography utilities, light and dark modes, and layout customization.

  • Dashboards & application examples

    Dashboard variations and example pages for projects, tasks, mail, files, calendars, profiles, and invoices.

  • Reusable UI & forms

    Cards, navigation, alerts, tabs, modal dialogs, offcanvas panels, form controls, advanced inputs, and upload examples.

  • Charts, tables & maps

    ApexCharts, Chart.js, ECharts, Grid.js, DataTables, jsVectorMap, Leaflet, and configurable Google Maps examples.

  • Development workflow

    SCSS compilation, HTML template-part assembly, dependency and asset copying, and BrowserSync preview through npm run dev.

  • Customer reference pages

    Standalone documentation and this changelog, with responsive navigation and theme-aware styling.

Integration reminder

Application records and interface actions are examples. Production authentication, storage, API connections, and server validation are supplied by your application.

Before installing an update

Protect your custom work

  1. Back up your application.

    Keep your existing source, configuration, and lockfile before replacing files.

  2. Review the changed files.

    Compare shared template parts, theme variables, page scripts, and dependency changes against your customizations. Avoid replacing the entire source folder without reviewing it.

  3. Install and rebuild.

    Run npm install, then npm run dev. The workflow recreates dist, so keep all changes in src.

  4. Verify your application.

    Check navigation, forms, charts, tables, light and dark modes, mobile layouts, and external API connections before deployment.
