Is Nexora UI built with Bootstrap?+

Yes. Nexora UI is an HTML admin template built on Bootstrap 5, with additional SCSS styling and vanilla JavaScript interactions.

Does the layout adapt to mobile screens?+

Yes. The page layouts and core interface patterns are designed to respond across desktop, tablet and mobile screen sizes.

Can I switch between light and dark themes?+

Yes. Theme modes are included, and this landing page remembers your theme preference on this device.

Can I customize the colors and components?+

SCSS variables and reusable component patterns give you a starting point for adapting the interface to your product.

What is included in the download?+

The template includes dashboard and application layouts, reusable UI components, responsive pages and documentation. Please check the product package for the current complete file list.
